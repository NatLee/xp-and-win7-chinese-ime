舊注音「ㄅ半」安裝批次檔

在新版 Windows 裝回 XP 舊注音和 WIN7 舊注音，用完可以用 DELETE.BAT 移除。

SETUP.BAT→ 按右鍵 →以系統管理員身分執行
SETUP.BAT 先檢查
  • 系統管理員權限
  • Windows 是 x86 或 x64
  • 再問兩題 Y／N
XP 舊注音 Y
複製 5 個檔案phonXP.ime、uniime.dll、3 個 .tbl
放到x64 版 → System32　x86 版 → SysWOW64
匯入REG.reg：鍵盤配置 E0010404
WIN7 舊注音 Y
匯入Win7.reg：不複製檔案
效果把 Windows 7 的注音加回內建的微軟注音
輸入法清單
中文（台灣）→ 新增鍵盤
